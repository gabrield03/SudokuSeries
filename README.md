# SudokuSeries

I have enjoyed playing Sudoku in my spare time over the past 10 years. The variation, Killer Sudoku, is my favorite - I play it almost daily.

This project hopes to achieve a few goals:
    - Design Sudoku and Killer Sudoku games that allow a user to play Easy, Medium, Hard, and Expert difficulty games.

    - Implement various auto-solvers for each.
        - 1. Auto-solving with backtracking
        - 2. Auto-solving with standard strategies
        - 3. Auto-solving with reinforcement learning

Due to the inerently more complex nature of Killer Sudoku, first iterations of this project will focus on the generic Sudoku game.
